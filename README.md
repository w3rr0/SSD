# Symulacje Systemów Dyskretnych

Wymagane jest stworzenie projektu dowolnej symulacji złożonej.
Nie może być to projekt do napisania w ciągu tygodnia lub dwóch, tylko coś większego.

**Note**: Nowe pomysly powinny zostac umieszczone w repozytorium w nastepujacy sposób:
- Streszczenie w pliku `ideas.md` przy odpowiedniej kategorii, jeśli jej nie ma należy ją stowrzyć.
- Bardziej szczegółowy opis i wszystkie informacje w osobnym plliku markdown (nazwę pliku umieścić w `ideas.md`)

Rzeczy które należy uwzględnić to dane dostępne w internecie oraz ewentualny sposób ich pozyskania, wyczyszczenia i sprowadzenia do nadającego się do użycia formatu, tezę którą moża udowodnić lub obalić za pomocą tej symulacji (nie musi być na start jakoś specjalnie szczegółowa)
